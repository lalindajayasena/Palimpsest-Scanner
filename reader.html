Reader help

  • Get a book in: scan with OCR on in the Scanner, and it appears here. Or tap Import .txt files and choose the .txt files from an earlier run (all parts together).
  • Read: tap Read. A− and A+ change the text size. 🌓 changes the colour: paper, sepia, dark.
  • ☰ opens chapters, go to page, and find a word.
  • ▶ Listen reads aloud from the paragraph you tapped. Tap another paragraph to jump there. Set the speed and a sleep timer next to the button.
  • Voices: the line at the bottom shows if English, Sinhala or Tamil voices are installed (✓ or ✗). Install missing voices in the phone's text-to-speech settings.
  • Screen: reading aloud needs the screen on. Chrome may stop it when the screen locks.
  • Your place in each book is remembered. Books are stored on this phone only.
  • Text mistakes come from the scan. Better light and Strong black and white help.
  • Install: tap ⬇ Install app, or the Chrome menu then Install app, to use it from your home screen.
